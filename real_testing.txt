B. Single 15-class XGBoost (1_xgboost_model)          one model, tuned class weights, labels all 15 classes

                                                     stage 1 Isolation Forest flags, stage 2 XGBoost names
                                                     (artifacts dated 2026-09-29, void until steps 2-5 re-run)

HOW TO READ THE NUMBERS
-----------------------
Every flow in these files is attack traffic (attacker -> port 22), so there are no
benign ground-truth flows. Therefore:
- Detection = share of flows the model calls an attack (not Benign).
- Recall = share of flows the model names SSH-Bruteforce.
- Accuracy on these files = recall, because every flow is an attack.
- Precision cannot be measured (no confirmed Benign flows).
- "Benign" in the tables below = flows the model missed (called normal).
Nothing was edited, scaled or relabelled. The 8 features the models never use are set to 0.
